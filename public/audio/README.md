# UI sounds

Served from `/audio/*` (this folder is under `public/`).
Register new clips in `lib/sounds.ts`.

| File | Plays when |
|------|------------|
| `theme-on.mp3` | Switching to **light** mode |
| `theme-off.mp3` | Switching to **dark** mode |

Keep clips short (~20–80ms), normalized, non-melodic ticks.
